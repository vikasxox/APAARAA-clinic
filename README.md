# APAARAAA Multi Speciality Centre website

A responsive, single-page clinic website bundle built from the clinic photos, centre signage and review screenshots supplied for this project.

## Files

- `index.html` – page content and site structure
- `style.css` – responsive styling, animations and layouts
- `script.js` – mobile menu, reveal-on-scroll effects, reading progress and current footer year
- `assets/clinic/` – supplied clinic interior photographs
- `assets/brand/` – supplied centre signage photo
- `assets/reviews/` – original supplied review screenshots for reference/archive

## Preview locally

Open `index.html` in a modern browser. No build tools or package installs are required. Google Fonts are loaded online when available; fallback fonts are included.

## Deploy

Upload the folder contents to any static host (for example, GitHub Pages, Netlify or Hostinger). Keep the `assets` folder beside `index.html` so image paths resolve correctly.

## Update contact details and content

Edit the phone numbers, address, hours, doctor names and reviews in `index.html`. The current bundle reflects details visible in the supplied screenshots and signage. Since doctor schedules, hours and services may change, confirm them with the centre before publishing updates.

## Notes

- The Google Maps link used in the buttons is the link supplied with the project.
- No clinic services beyond those supported by the supplied material are presented as a confirmed speciality. The diagnostics section says to call to confirm tests and availability.
- Review text is shown as selected excerpts from the screenshots supplied by the user.
